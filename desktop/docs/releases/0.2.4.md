# Desktop 0.2.4 — unsigned prerelease candidate

Status: preparation only; not published. Intended tag: `desktop-v0.2.4`.

## Release announcement draft

Umbod Desktop 0.2.4 is a macOS-only update for Apple Silicon, macOS 14 or later.
The app is ad-hoc signed and **not notarized**. This is an unsigned prerelease,
not a signed production release. Do not disable macOS security protections.

### Changes since 0.2.3

- Improved connector onboarding and browser sign-in feedback.
- Fixed publication of enabled tools and preserved connections when renamed.
- Stop old gateways when their profile is replaced.
- Simplified Settings and connector setup; MCP copy feedback stays inline.
- Removed the Windows app and legacy Rust backend. No Windows installer is
  included in this release; previously published assets remain unchanged.
- Added a developer-facing local production-app installer with bundle checks
  and an application backup. This is not automatic update installation.

### Upgrade instructions

**Download this first macOS-only update manually from https://umbod.ai/download/
when 0.2.4 is published there.** Older apps require a Windows entry in update
metadata and cannot read the new macOS-only manifest. Version 0.2.4 accepts
macOS-only manifests for subsequent update checks.

Mount the DMG and copy Umbod.app to Applications. Verify the download against
SHA256SUMS with `shasum -a 256`. Credentials remain in Keychain. Closing the
window leaves the backend running; use Settings to stop it.

No Intel Mac, Windows or Linux build is provided. Automatic installation of
updates, certification against real OAuth providers, and legacy SSE-only
upstreams remain unsupported. CI runs on macOS 26 ARM64; macOS 14 runtime
acceptance has not been established.
