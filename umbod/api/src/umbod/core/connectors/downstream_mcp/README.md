# Downstream MCP connectors

`models.py` defines connector definitions, discovery data and creation commands. Shared creation retains its discriminated `CreateConnectorDefinition` union. `CreatePersonalOAuthConnectorDefinition` is a separate personal creation operation with optional administrator-owned OAuth configuration.

`management/` coordinates creation, updates, deletion and queries through the aggregate unit-of-work port. `DownstreamConnectorCreator.create_personal_oauth()` checks identity and public-path uniqueness, then atomically creates the definition while clearing shared credentials, catalogue, health and publication and reconciling an empty activation set. It does not invoke preparation or probing. Generic personal edits remain rejected; dedicated revision-checked OAuth policy replacement invalidates personal authorizations and attempts without changing publication or grants.

`publishing/` permits personal approval without discovery while preserving shared catalogue and public-tool-name requirements. `permissions.py` decorates an existing assignable permission catalogue with published personal connector targets only; it does not synthesize tools or change runtime readiness.

`catalog/`, `probe/`, `connection.py` and `adapters/` implement shared discovery and connection integration. `oauth/` implements shared authorization orchestration. `stores/` supplies persistence adapters. Its production factory uses `DefinitionBoundPersonalConnectionStore`, which validates personal connector existence inside the same serialized transaction as every personal mutation. Aggregate deletion therefore cannot be followed by orphaned enablement or stale authorization writes. The detached `EncryptedPersonalConnectionStore` retains its standalone lifecycle contract. `personal_connections/` owns principal-scoped connection lifecycle, selection and durable personal authorization. `personal_oauth_configuration/` defines administrator-approved scopes, explicit dynamic/preconfigured client variants and the encrypted configuration-store port. Its [index](personal_oauth_configuration/README.md) describes policy lifecycle. `adapters/personal_oauth/` supplies resumable public/confidential-client OAuth independently of shared orchestration. Attempt storage and aggregate deletion share transactional boundaries; personal authorization never enables runtime execution.

The administration boundary is indexed in `rest/connectors/downstream_mcp/README.md`.
