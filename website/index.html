A setup you control

Keep your tool setup
in one place.

Umbod Desktop is a single-user app with a local gateway. Use it with compatible MCP clients without running a server stack.

Connect local and remote tools
Add an executable MCP server or a Streamable HTTP endpoint. Discover its tools and enable the ones you need.
Set permissions across your clients
New tools start disabled. When you change a tool permission, it applies to subsequent calls from every client connected to this local gateway.
Keep credentials in the OS vault
Umbod stores credentials in macOS Keychain or Windows Credential Manager, with no plaintext fallback. OAuth supports native public clients with PKCE; individual providers are not certified.
See usage and manage the gateway
Check tool usage counts in the app. Closing the window leaves the gateway running; stop or restart it from Settings.

Before you start

A few practical details.

Does local mean everything stays on my computer?

The gateway and its configuration run locally. Remote MCP servers and your chosen agent can send data to their own services. Their privacy policies still apply.

What does the desktop app support?

Local stdio and remote Streamable HTTP MCP tools. Legacy standalone SSE servers, resources, prompts, sampling, and argument-level policies are not supported. Windows stdio connectors need an executable such as node.exe, not a .cmd or .bat wrapper.

Is Desktop the same as the enterprise edition?

No. Desktop is for one person. The enterprise edition manages shared connectors and group access on your infrastructure. Configuration portability between the editions is not implemented.

Can I build it myself?

Yes. The desktop build instructions cover prerequisites and local builds. There is no automatic updater or login supervisor yet.
