# Design Pattern Markdown Guides

These guides are implementation-oriented summaries of the 22 classic design patterns listed in the Refactoring.Guru catalog.

The files are intentionally not normalized into the same rigid template. Each guide prioritizes the exact implementation shape, Mermaid class diagram, refactoring signals, and disambiguation rules needed to recognize and implement the pattern.
